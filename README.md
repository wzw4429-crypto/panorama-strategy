# PSE · 全景式历史战略模拟引擎（可玩原型）

> **真实地理世界地图**（Natural Earth 110m + Voronoi 省份剖分）· 59 个国家 · 1293 个省份 · 26 个海区
> 时间粒度 = 1 游戏小时 · 无构建步骤 · 无第三方依赖 · 双击 `index.html` 或用 `node server.js` 起服务即可开玩

---

## 1. 怎么开玩

```powershell
node server.js 8787        # 浏览器打开 http://127.0.0.1:8787/
# 或直接双击 index.html
```

开局界面可选 **国家（59 个，★ 为八大主要国家）**、**剧本（1936 / 1939）**、**难度（征召/标准/老兵）**、**铁人模式**。

### 操作
| 操作 | 作用 |
|---|---|
| 左键点省份 | 右侧显示地质/天气/所有者/控制者/胜利点/补给/抵抗/驻军/工厂 |
| 拖动地图 / 滚轮 / 双击 | 平移 / 缩放 / 居中 |
| 「陆军」面板 → 选中 / 全选 | 挑选要指挥的师团 |
| **右键点地图** 或 详情里的按钮 | 下达行军/进攻命令 |
| 空格 · 1-5 · L · S · `~` | 暂停 · 速度 · 切图层 · 存档 · 控制台 |
| **Shift+F** · **Esc** | 侧栏面板（国策/科研/生产…）全屏查看 · 退出全屏 |

### 新手路线（德国 1936 推荐）
1. **国策**：点树上的节点启动（分支互斥，历史路线如"莱茵兰→安施卢斯→苏台德→但泽→苏德条约→巴巴罗萨"）
2. **科研**：给每个科研槽选项目（工业优先；学说一旦选定不可改）
3. **生产**：分配军工到步兵装备/火炮/坦克产线；换型会触发效率归零+冷却
4. **装备**：自定义坦克（底盘/火炮/装甲/引擎）并定型投产；向别国买装备或挂牌出售
5. **陆军**：征兵 → 给集团军任命将领 → 下"推进/强攻"命令 → 右键推线
6. **海军/空军**：把舰队派往海区抢制海权（≥40% 才能登陆）；给联队分配任务
7. **谍报/外交**：成立情报局派特工；改善关系、结盟、租借、制造借口、宣战
8. **图层**：`补给网`=枢纽+线路管网图，`战线`=接触线+进攻箭头，`空域/海区`=区域叠加

**运行测试**
```powershell
node --max-old-space-size=3072 tests/headless.js 3    # 157 项断言
node --max-old-space-size=3072 tests/dom-smoke.js     # 28 项断言
node tools/build-map.js                               # 重新生成地图（约 1 分钟）
```

**开发与构建（TypeScript）**

- `src/*.ts` 是唯一真源；`tsc -p tsconfig.json` 就地 emit 出 `src/*.js`（index.html / server.js / tests / CI 全部只认 `.js`，加载方式不变）
- 本地改码后编译：`npm run build`（或 `npx tsc -p tsconfig.json`）；`npm run watch` 持续编译
- CI 打包 APK 前会自动跑一遍 `tsc`，保证产物与源码同步
- 当前 `tsc` **0 错误**；类型收紧（给 `World/Country/Province/Division` 补接口、把字符串 tag 字面量化）是后续增量工作——国家 tag 写错（如 AUS/AUT）将变成编译期错误

**平台适配层（Web / PWA / 桌面壳）**

`src/platform.ts` 是页面与宿主之间的唯一接口：`PSE.Platform` 提供 `kind()`（展示标签：`tauri` / `electron` / `webview2` / `pwa` / `web`，宿主未声明时为 `host`）、`isDesktop()`（**看有没有宿主**）、`store()`（存档落地）、`download()` / `pickText()`（导出/导入存档）、`notify()`、`fullscreen()`、`openExternal()`、`info()`。

- 浏览器（含 Android WebView）下全部退回原行为：localStorage + `<a download>` + `<input type=file>`，**无宿主也能玩**
- 桌面壳只需在页面加载前注入 `window.PSE_HOST`（`{kind, desktop?, kv:{get,set,remove,keys}, saveFile, openFile, notify, fullscreen, openExternal}`）即可接管存档、文件对话框、通知与窗口全屏；宿主方法逐个探测，缺一个只影响那一项
- 桌面判定以「有没有宿主」为准：Go + WebView2 壳报 `kind: 'webview2'` 也算桌面（`kind` 只作展示）；宿主显式写 `desktop: false` 时才按 web 处理
- 存档面板新增「导入存档」，桌面壳下会换成原生打开对话框（走 `PSE_HOST.openFile`）
- 接入点与协议细节见 `HANDOVER.md` §3/§7

**Windows 桌面版（Go + WebView2，已完成）**

`desktop\` 下是独立于 web 的桌面壳：Go 静态编译的单文件 exe（3.56 MB）+ `www\`（就是本仓库的静态产物），用 `SetVirtualHostNameToFolderMapping` 把 www 映射成 `https://panorama.local/`（**不用 `file://`**，否则 localStorage 会丢存档），存档落在 `%LOCALAPPDATA%\PSE-Panorama`；F11 全屏、窗口位置记忆、单实例、PerMonitorV2 DPI、禁用 WebView2 默认右键菜单，游戏自己的 `F`/`Shift+F`/`Esc` 等按键全部透传；exe 内嵌 `app.ico`（与游戏同源的金色地球图标）与版本信息——文件图标、标题栏、任务栏、Alt-Tab 四处一致。

```powershell
powershell -ExecutionPolicy Bypass -File desktop\build.ps1 -Zip        # 出 exe + www + zip
powershell -ExecutionPolicy Bypass -File desktop\verify.ps1 -FreshUserData  # 9 组 27 项端到端验收
```

桌面壳只消费 web 产物，**不修改任何游戏代码**；详细设计、验收证据与排障见 `desktop\README.md`、`HANDOVER.md` §7。

## 5. 已知边界

- **多人联机**未实现（单机原型）；**图形化 MOD 编辑器**未实现（有数据注入 API）。
- 海军为"舰队-海区"抽象（无逐舰航行与阵形）；空军为"联队-任务"抽象（无逐架次空战）。
- 河流渡河惩罚未建模（多边形地图未含水系数据）；两栖/伞降有指令与惩罚但无专用登陆舰艇细分。
- 部分小国（如葡萄牙 2 省）省份数偏少，属 Voronoi 目标数下限与几何面积共同作用的结果。
- 完整设计规格（八大子系统、类图、战斗伪代码、国策树 DSL、ADR）见 `../grand-strategy-engine-design/`。

## 6. Android APK（GitHub Actions 自动构建）

仓库自带 `.github/workflows/build-apk.yml`，每次 push `main` 自动构建：

1. `tsc` 编译 TypeScript → emit `src/*.js`
2. 从 Secret 解码固定签名密钥库 `pse-release.p12`（PKCS#12 / RSA 2048 / 别名 `pse`）
3. 把 `index.html + src/ + data/` 复制进 `android/app/src/main/assets/www/`（仓库内为唯一真源，避免副本漂移）
4. JDK 17 + Gradle 8.9 + AGP 8.5.2 执行 `assembleRelease`（固定签名）并验签
5. 产物 `panorama-strategy.apk` 上传为 Actions Artifact（名 `panorama-strategy-apk`）

**安装**：GitHub → Actions → “Build Android APK” → 最新运行 → Artifacts 下载解压 → 手机侧载（允许未知来源）。
APK 为 WebView 壳（`android/…/MainActivity.java`）：横屏、常亮、localStorage 存档、**完全离线可玩**，无任何网络权限需求。
启动带封面（金色地球 Logo，深色底），图标为自适应图标（API 26+）/ 矢量兜底（API 24-25）。
触屏操作：单指拖动平移、双指捏合缩放、轻点选省、双击居中放大；UI 已按横屏手机（如红米 K80 1067×480 CSS px）适配。

**固定签名说明**
- 密钥库**不在仓库内**（`.gitignore` 排除 `*.p12`），保存在 GitHub Secrets：`PANORAMA_KEYSTORE_B64`（base64）+ `PANORAMA_KEYSTORE_PASSWORD`
- 本地备份位置：`android/app/pse-release.p12`（密码 `panorama2026`，别名 `pse`，有效期 10000 天）——**请务必另行备份**，丢失后老用户无法覆盖升级（只能卸载重装）
- 本地构建 release：把 p12 放到 `android/app/` 并设环境变量 `PANORAMA_KEYSTORE_PASSWORD`，`gradle -p android assembleRelease` 即自动签名
- 重新生成密钥库（会改变签名身份，老用户需卸载重装）：
  ```bash
  openssl req -x509 -newkey rsa:2048 -keyout k.pem -out c.pem -days 10000 -nodes -subj "/CN=Panorama Strategy/O=PSE/C=CN"
  openssl pkcs12 -export -in c.pem -inkey k.pem -out android/app/pse-release.p12 -name pse -passout pass:<密码>
  ```

本地构建（可选）：Android SDK 34 + JDK 17，`gradle -p android assembleDebug`（先手动把 web 资源拷入 `assets/www/`）。
